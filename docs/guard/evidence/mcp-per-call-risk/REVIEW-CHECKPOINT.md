The retained production default derives categories twice in one authority invocation; signals already derive once. The original count assertion failed against that default. The prototype attempted to share only invocation-local categories between the existing private hash and current-policy kernels, while keeping the existing package classifier and final writer.

Those failures exposed skipped public hash/evaluator substitutions, including existing terminal-block and package behavior. They were semantic compatibility failures and were retained rather than rewritten as successful tests.

That final abort was not sufficient to protect the saved-state boundary.
