## Resulting behavior

- **Encrypted post-tool output:** Pi and OMP can provide large post-tool output through their existing encrypted reference. On POSIX, Rust opens the bounded private file without following links, verifies ownership, modes, file identity, hash and AES-256-GCM authentication, validates the inner event and metadata, and evaluates the actual content under the original absolute deadline. The receipt retains the outer request commitment and reference kind. Windows encrypted references remain unsupported.
- **Daemon imports:** importing lightweight daemon surfaces no longer eagerly imports the seven manager exports. Explicit access still returns the original function, with shared state initialized before use. All 11 public exports, normal imports, reload, directory listing and monkeypatch behavior have controls. Manager import errors and side effects now occur on first access; direct inspection of the package dictionary can observe unresolved names.
- **First-generation admission:** a fully observed, stable empty command namespace can publish its initial native generation. Unknown, partial, symlink/nonregular or subsequently changed authority remains refused.
- **Windows private-file replacement:** eligible Windows systems use the reviewed POSIX replacement capability while retaining OS error semantics and private-file safety checks.
- **Risk reuse:** unchanged exact request inputs reuse category/signal work. Input, authority, catalog or implementation changes invalidate reuse, including pending approvals and the final deadline fence.
- **Codex approval resume:** browser resume consumes the same two root transport timeout hints as initial HTTP ingress, allowing native revalidation to see the original committed request. Nested input, source/correlation identity, signed approval, current policy, deadlines and replay checks remain binding.
- **Response contracts:** current Cline, auxiliary-event and registration-roster fixtures capture JSON/stdout/stderr/exit behavior for mode/posture, native misses, integrity/size failures, permissions and lifecycle events.
